# Section priority rules

这些规则来自《手把手教你读财报》对年报阅读重点的划分，并针对长篇 Markdown 做了“低上下文读取”改写。

## P0 必读
- 审计意见
- 财务会计报告 / 财务报表
  - 合并资产负债表
  - 合并利润表
  - 合并现金流量表
  - 与核心异常项目直接相关的附注
- 管理层讨论与分析中的：
  - 主营业务分析
  - 资产及负债状况分析
  - 投资状况分析
- 重要事项

## P1 条件阅读
- 股份变动及股东情况
- 员工情况 / 董监高与员工情况
- 公司未来发展的展望

## P2 默认跳过
- 释义
- 公司治理
- 内部控制
- 备查文件目录
- 其他低信息密度的程序化披露

## Upgrade triggers
如果命中下列触发词，即使原区段是 P1/P2，也可以提升优先级：
- 非标审计
- 保留意见
- 强调事项
- 重大诉讼
- 重大担保
- 关联交易异常
- 资金占用
- 债务违约
- 退市风险
- 大额减值
- 存货跌价
- 应收异常
- 现金流恶化

## Recommended reading recipes

1. 审计意见
2. 主营业务分析
3. 资产及负债状况分析
4. 重要事项
5. 三张主表

### risk-check
1. 审计意见
2. 重要事项
3. 资产及负债状况分析
4. 现金流量表
5. 异常项相关附注

### multi-year-compare

2. 提取趋势与异常
3. 仅回查异常年份的对应区段
