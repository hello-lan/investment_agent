# Annual Report Business Analyst

```text
base_dir = data/reports/result
```

后文的 `{base_dir}` 都指上面这一行。改输出目录只改这里。路径相对项目根，用 `/`。写出的文件是 `{base_dir}/<code>/<report>.<后缀>.md`。

这个技能分析合并三大报表。简化、重分类和指标计算是读表手段。前三件事彼此独立，第四件事依赖前两份成功文件：

- 合并资产负债表重分类为生产、经营、投资资产和融资、分配、经营负债
- 合并利润表收成逐级利润，并用两侧恒等式收口
- 合并现金流量表摘录主表，计算五个质量指标，并判断现金流画像
- 经营阅读：按占比和变动读合并附注，并按索引阅读管理层讨论，与报表数字互相印证

母公司报表不进入任何结果。每件事都先从 `<report>.sections.json` 取出要读的行号，再只读那一段，然后自己写出结果。不要运行 Python 脚本生成结果，也不要把年报全文读进对话。做资产负债表或利润表时不顺带做现金流，反过来也不顺带。只写出资产负债表和利润表其中一张成功文件时，不做经营阅读。两份都是成功文件之后才做，不在做单张表时顺带做。

## 怎么定位和读取

路径相对项目根，用 `/`。

1. 确认年报同目录有 `<report>.sections.json`。没有就先跑 `build-annual-report-index`。禁止用 `read_file` / `search_text` 扫年报来找这三张表
2. 在索引里找章节。标题含「合并资产负债表」「合并利润表」或「合并现金流量表」，且不含「母公司」。常见标题是 `财务报告-合并资产负债表`、`财务报告-合并利润表`、`财务报告-合并现金流量表`。节点在 `chapters` 里，也可能在子节点。取该节点的 `line_start`、`line_end`。行号从 1 计，闭区间
3. 索引不大就直接 `read_file` 这份 JSON。索引很长时，只用 `search_text` 在这份 JSON 里搜当前任务要的标题，读命中附近的 `title`、`line_start`、`line_end`。同名多条时，用带「财务报告-」前缀、且行号落在正文而不是目录的那一条
4. 用行号读年报正文。`max_lines` 取区间长度，单次不超过 400。返回头里 `has_more=true` 时，用 `next_start_line` 续读，直到 `line_end`

```text
read_file(
  path="data/reports/md/<code>/<report>.md",
  start_line=<line_start>,
  max_lines=<line_end - line_start + 1，且不超过 400>
)
```

读到「母公司资产负债表」「母公司利润表」或「母公司现金流量表」就停，后面的行不进入结果。

5. 按对应任务的口径，用 `write_file` 把结果写到 `{base_dir}/<code>/`。文件名是 `<report>.<后缀>.md`。金额从刚读到的表抄录并计算，不估算、不改主表数字。目录不存在就先建目录再写。禁止写到年报同目录 `data/reports/md/<code>/`

结果只允许落在这些路径：

```text
{base_dir}/<code>/<report>.simplified-bs.md
{base_dir}/<code>/<report>.simplified-bs.review.md
{base_dir}/<code>/<report>.simplified-is.md
{base_dir}/<code>/<report>.cash-flow-analysis.md
{base_dir}/<code>/<report>.cash-flow-analysis.review.md
{base_dir}/<code>/<report>.operating-reading.md
```

主表上必须拆开的混合科目，主表「其中」能拆完的，按其中项拆。拆不完时，再在同一份索引里找合并附注中的同名科目（`财务报告-合并报表附注`，或标题含「合并财务报表项目注释」的节点及其 `children`），只读该科目的 `line_start` 到 `line_end`。标题后紧邻、标题含「续」的下一段一并读。子项两年分别加总必须等于主表该科目。对不上就不写简化表。

## 资产负债表

归类前读 `references/balance-sheet-rules.md`。重分类和轧平后的结构分析都在这一份里。

1. 按上一节读取合并资产负债表
2. 混合科目拆平，并且三类资产、三类负债、所有者权益轧平之后，写 `{base_dir}/<code>/<report>.simplified-bs.md`。轧平是指资产总计 = 负债合计 + 所有者权益，差额为 0.00（按元，保留到分）
3. 轧平后按同一份 `references/balance-sheet-rules.md` 的「结构分析」做结构分析，写在同一份简化表后面。这一步仍只按索引行号读它点名的附注和「资产及负债状况分析」，不要重读合并资产负债表
4. 索引没有合并资产负债表行号，或主表缺资产总计、负债合计、所有者权益合计，或拆分对不上、轧差不为 0：停止。不写简化表，改写 `{base_dir}/<code>/<report>.simplified-bs.review.md`，列出缺什么、已读行号、主表金额和差在哪里。不要编造金额

### 产出

`{base_dir}/<code>/<report>.simplified-bs.md`：

- 简化表：生产类资产、经营类资产、投资类资产、融资性负债、分配性负债、经营性负债、所有者权益。单位亿元，保留两位小数
- 明细表：每一类的科目、两年金额、变动、来源（主表 / 附注拆分 / 主表其中项）。单位元，保留到分
- 轧差：三类资产、三类负债、权益明细、资产 = 负债 + 权益

### 口径摘要

资产：

- 生产类资产：固定资产、在建工程、工程物资、固定资产清理、生产性生物资产、油气资产、开发支出、长期待摊费用、无形资产、商誉、使用权资产，以及购建相关预付款
- 经营类资产：货币资金、应收票据、应收账款、应收款项融资、预付款项、其他应收款、存货、合同资产、长期应收款、递延所得税资产，以及销售形成的其他应收
- 投资类资产：交易性金融资产、衍生金融资产、长期股权投资、其他非流动金融资产、投资性房地产、债权投资及其他对外投资

负债：

- 融资性负债：短期借款、交易性金融负债、衍生金融负债、长期借款、应付债券，以及一年内到期的借款和债券
- 分配性负债：应付股利、应交企业所得税
- 经营性负债：除上述两项以外的负债。租赁负债、预计负债、长期应付款、递延收益、递延所得税负债、应付职工薪酬、经营性往来都在这里

所有者权益不重分类，库存股从权益中扣减。

必须拆开、不能整笔归类的主表科目：应交税费、其他应付款、一年内到期的非流动负债、一年内到期的非流动资产、其他非流动资产、其他流动资产。拆分方式以 `references/balance-sheet-rules.md` 为准。

## 简化表之后的结构分析

简化表写完并且轧差为 0 之后，按 `references/balance-sheet-rules.md` 的「结构分析」继续。金额来自简化表，原因来自指定附注。

1. 标出变动较大的负债类别和类内科目。类别变动率 ≥ 30% 或变动金额 ≥ 10 亿元；类内科目变动率 ≥ 30% 且金额 ≥ 1 亿元，或变动金额 ≥ 10 亿元。类别合计不大、内部对冲很大时，仍要拆开
2. 只按索引行号读对应合并附注，以及「资产及负债状况分析」的重大变动说明。附注没有文字原因时，才允许用该文件列出的现金流和所得税费用行做交叉核对
3. 附注和重大变动说明都解释不了的变动，写明示警，并摘录附注实际写了什么。讨论写「无重大变动」或留空、但金额已达到变动标准的，同样示警
4. 计算四个比率，两年都算：
   - 有息负债率 = 融资性负债 / 总资产。大于 60% 额外示警。租赁负债不计入有息负债
   - 生产资产 / 总资产。生产资产 = 生产类资产 − 商誉 − 土地使用权以外的无形资产。土地使用权取无形资产附注账面价值，没有土地行就按 0
   - 应收 / 总资产。应收 = 带「应收」的科目（含附注确认的一年内到期长期应收款）− 银行承兑汇票。大于 30% 额外提醒。财务公司承兑、商业承兑不减
   - 货币资金 / 有息负债。只报告，不另设示警线

结构分析的输出放在简化表和明细表之后：变动表、附注原因或示警、四行指标、生产资产构成、应收扣除明细。

## 合并利润表简化

先读 `references/income-statement-rules.md`。只处理**合并利润表**。

按企业会计准则整理成五层：

- 毛利 = 营业收入 − 营业成本。不减税金及附加。主表没有这一行
- 经营利润 = 毛利 − 税金及附加 − 费用。费用 = 销售费用 + 管理费用 + 研发费用，简化表只列这一行。这是分析口径。财务费用不并进费用，先不减
- 营业利润是法定小计。从经营利润再减财务费用，并加上其他收益、投资收益、净敞口套期收益、公允价值变动收益、减值损失、资产处置收益。减值损失 = 信用减值损失 + 资产减值损失，简化表只列这一行，损失按主表符号相加。公允价值变动收益、资产处置收益不并进减值损失
- 利润总额 = 营业利润 + 营业外收入 − 营业外支出
- 净利润 = 利润总额 − 所得税费用。再拆归母净利润和少数股东损益，拆分不重复加
- 不单列经常性净利润。扣非归母净利润放在净利润之后，只作对照

最终恒等式里，费用和减值损失各是左侧的一行。财务费用仍单独留在左侧，沿用主表符号。减值损失在左侧以损失为正：先把信用减值损失、资产减值损失各自按主表符号换成损失为正，再相加。毛利、经营利润、营业利润、利润总额不进入两侧。

### 执行顺序

1. 按「怎么定位和读取」读取合并利润表
2. 扣非归母净利润需要非经常性损益合计。在同一份索引里找标题含「非经常性损益」且不含「母公司」的节点，只读该行号范围。没有这个节点就跳过扣非，并在简化表里写明索引没有该合计
3. 用读到的主表复原毛利、经营利润、营业利润、利润总额、净利润，并配平两侧恒等式。营业利润、利润总额、净利润必须与主表一致；左侧合计必须等于右侧合计。配平用元。亿元用于色块表和瀑布展示
4. 配平后写 `{base_dir}/<code>/<report>.simplified-is.md`。需要附注明细时，按 `references/income-statement-rules.md` 的附注清单，用索引行号补在瀑布后面。明细合计必须等于主表该行
5. 索引没有合并利润表行号，主表缺营业收入、营业成本、营业利润、利润总额或净利润，或复原的法定小计、恒等式对不上：停止，不写简化表，说明哪一行对不上。不要编造金额，不要改主表数字去配平

### 产出

`{base_dir}/<code>/<report>.simplified-is.md`：

- 两列色块表（HTML）：每年一张，两年并排。左列是消耗加净利润，右列是收益来源，两列等高、等宽、贴紧。格子高度按该侧金额绝对值分配。费用、减值损失各占一格。成本费用是深灰块，净利润和右侧收入是橙色块，文字黑色并居中。科目和亿元金额写在同一行，中间空一格，不要把金额换到下一行。块之间用细白线分开。财务费用等净收益、减值净转回、右侧净损失留在原侧，高度仍按绝对值，改用浅底虚线框。做法见 `references/income-statement-rules.md` 的「色块表」。不要写成左右逐行对齐的 markdown 表，也不要用附图里的日本科目名
- 简化瀑布（亿元）：从营业收入走到净利润，标出分析口径和法定小计。销售费用、管理费用、研发费用合并为「减：费用」一行；信用减值损失、资产减值损失合并为「加：减值损失」一行，沿用主表符号。来源金额写在对应行下面，两年分别相加必须等于这一行。报表没有研发费用、信用减值损失或资产减值损失时，缺的按 0，并写明
- 净利润归属和扣非对照
- 两侧金额（元）和与主表营业利润、利润总额、净利润的校验

## 合并现金流量表分析

先读 `references/cash-flow-analysis.md`。只处理**合并现金流量表**。这一步独立，不在简化资产负债表或利润表时顺带做。

### 执行顺序

1. 按「怎么定位和读取」读取合并现金流量表。读到「母公司现金流量表」就停
2. 抄录本年、上年全部行，保留附注号、小计、净额、汇率变动、现金净增加、年初和年末余额。按参考文件做勾稽。三类流入减流出不等于该类净额，三类净额加汇率影响不等于现金净增加，或年初余额加净增加不等于年末余额：停止，不写分析，改写 `{base_dir}/<code>/<report>.cash-flow-analysis.review.md`，列出已读行号、主表金额和差额。不要编造金额，不要改主表数字去配平
3. 按索引读取合并利润表，只用营业收入和净利润。净利润用合并净利润，不用归属于母公司所有者的净利润
4. 期末现金及现金等价物余额 / 有息负债的分母，按索引读取合并资产负债表，只取短期借款、交易性金融负债、衍生金融负债、长期借款、应付债券、一年内到期的非流动负债。一年内到期的非流动负债只读合并附注同名科目及其标题含「续」的相邻节点，拆出借款和债券。这一步不写简化资产负债表
5. 按参考文件计算五个指标，本年和上年都算
6. 指标 3 要剔除滚动项。在同一份索引里读合并附注「现金流量表项目」及其标题含「续」的相邻节点，取与投资活动有关的现金，以及筹资活动负债变动里的应付股利。委托理财：索引里有标题含「委托理财」或「现金资产管理」的节点就只读该节点；没有时，只在「第六节 重要事项」的行号范围内搜索「委托理财」，读命中附近的少量行，不读整节
7. 用三个净额的正负对照参考文件的八种画像。写出类型名称和该类型的关注要点，并只做该类型规定的数字检验。要点只用参考文件里的文字，不重新检索网页
8. 用 `write_file` 写到 `{base_dir}/<code>/<report>.cash-flow-analysis.md`

### 产出

`{base_dir}/<code>/<report>.cash-flow-analysis.md`：

- 合并现金流量表本年、上年全文。单位元，与主表一致
- 勾稽：三类净额和现金净增加
- 五个指标，两年各算。指标 3 列出报表原值、剔除理财后、再剔除同类对滚后。写明剔除了什么、两侧金额，以及剔除后剩余流入和流出的构成。现金及现金等价物净增加额写出金额并回答是否大于 0。期末现金及现金等价物余额 / 有息负债写出比值，以及计入有息负债的科目和金额
- 两年的经营、投资、筹资符号、画像名称、关注要点，以及该类型要求的数字检验。写明只有一两年同号，不能认定秉性

## 经营阅读

先读 `references/operating-reading.md`。只在本次已经写出成功的 `{report}.simplified-bs.md` 和 `{report}.simplified-is.md` 之后做。任一是复核文件或未产出，就跳过，不写经营阅读。不改已写出的简化表、瀑布和恒等式。不重读三张主表。现金流量表成功文件已有时，只从中抄销售收现比，不为此重读现金流量表。

这一步写科目特性，并把附注和管理层讨论里的经营事实与报表数字分成自洽、背离或关联不大。不引用排雷规则，不给风险评级。

### 执行顺序

1. 按参考文件的入选标准，从两份简化文件取金额。资产负债表看明细里的科目，利润表看瀑布上的项目。占比和变动用这些金额计算。最多 12 个，超出的在入选表写「未读」
2. 结构分析已经写过变动原因的负债，不重读附注去重复原因。该科目因占比入选时，只补账龄、担保、借款条件、构成
3. 按参考文件定位合并附注。只读入选科目的同名节点及其标题含「续」的下一段。节点超过 400 行时，不读整条附注，按参考文件点名的表读。索引没有该科目，或附注只有余额没有构成：写明，并按参考文件示警
4. 管理层讨论先看索引，再分块。标题含「管理层讨论与分析」或「经营情况讨论与分析」的章优先；都没有时用「董事会报告」下的经营讨论。列出该章全部 `children`，并补上 children 没盖住的行号，标题写「未单独成节」。不因标题丢掉任何一块
5. 一块 ≤ 150 行，当前 Agent 按行号自己读。一块 > 150 行，按参考文件写成自包含工作单元：输入按参考文件模板写全，含要摘的事实、锚点和印证口径，输出只有规定的摘要。当前 Agent 已有隔离执行入口时，把整个单元交出去，只收回输出；互不依赖的单元可以同时交。没有入口，或某次交不出去、被拒绝，就由当前 Agent 按块续读，单次不超过 400 行，直到该块的 `line_end`。无论谁读的，上下文里只留输出
