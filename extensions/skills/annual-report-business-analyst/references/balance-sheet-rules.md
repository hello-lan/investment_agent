# 合并资产负债表重分类与结构分析

只重分类合并资产负债表。母公司报表不使用。

金额以主表账面价值为准。附注只用于把混合科目拆进不同大类。同一大类内部能在主表看清单笔的，明细保留主表科目，不把附注再展开一遍。

简化表轧平之后才做结构分析。金额用简化表和明细表里的元，不要改已归类的科目。比率两年都算。亿元只用于展示。

结构分析只按章节索引的 `line_start`、`line_end` 读取「结构分析」里列出的段落。不要通读年报。

## 生产类资产

固定资产、在建工程、工程物资、固定资产清理、生产性生物资产、油气资产、开发支出、长期待摊费用、无形资产、商誉，以及与日常生产制造相关的同类科目。

同时归入生产类资产：

- 使用权资产（租入房屋、设备，替代自有固定资产）
- 其他非流动资产中的预付设备款、预付基建款、预付房产款、预付土地款、预付工程款
- 同一张预付款附注里的「其他」

## 经营类资产

为企业销售商品或提供劳务服务而持有的资产。包括货币资金、存货、因销售商品或提供劳务产生的应收票据、应收账款、应收款项融资、应收利息、应收股利、长期应收款、其他应收款、预付款项、合同资产。

同时归入经营类资产：

- 一年内到期的长期应收款、长期合同资产
- 递延所得税资产
- 其他流动资产中的待抵扣进项税、预缴税费；若整笔都不含理财或交易性金融资产，主表「其他流动资产」保持一行

货币资金里的受限保证金仍留在货币资金。

## 投资类资产

公司把现金拿去投资形成的股权、债券、基金、信托、理财、投资性房地产及其他金融资产。包括投资性房地产、持有至到期投资、债权投资、其他债权投资、其他权益工具投资、交易性金融资产、衍生金融资产、长期股权投资、其他非流动金融资产。

应收款项融资来自销售收款，归经营类资产，不归投资类资产。

## 融资性负债

因运营或投资需要，借贷或发行债券形成的负债。包括短期借款、交易性金融负债、衍生金融负债、长期借款、应付债券，以及一年内到期的长期借款、一年内到期的应付债券。

## 分配性负债

伴随盈利产生、截至报表日尚未支付的股利和所得税。只包括应付股利和应交企业所得税。

增值税、城建税、教育费附加和其他应交税费归经营性负债。递延所得税负债不是应交所得税，归经营性负债。

## 经营性负债

除融资性负债和分配性负债以外的负债，主要包括伴随经营活动产生的负债。

包括应付票据、应付账款、合同负债、预收款项、应付职工薪酬、其他应付款（去掉应付股利）、其他流动负债、预计负债、租赁负债、长期应付款、递延收益、递延所得税负债、其他非流动负债。

一年内到期的租赁负债、一年内到期的预计负债、一年内到期的长期应付款，跟对应的长期科目一样，归经营性负债。

## 所有者权益

不重分类。股本、资本公积、库存股、其他综合收益、盈余公积、未分配利润、少数股东权益及其他权益科目保持原名。名称以「减：」开头的库存股，从权益合计中扣减。

## 必须拆开的主表科目

| 主表科目 | 怎么拆 |
|---|---|
| 应交税费 | 企业所得税进入分配性负债，其余进入经营性负债 |
| 其他应付款 | 主表「其中：应付股利」进入分配性负债，余额进入经营性负债 |
| 一年内到期的非流动负债 | 借款、债券进入融资性负债；租赁、预计负债、长期应付款进入经营性负债 |
| 一年内到期的非流动资产 | 长期应收款进入经营类资产；债权投资、理财进入投资类资产 |
| 其他非流动资产 | 合同资产进入经营类资产；购建预付款进入生产类资产 |
| 其他流动资产 | 含理财、交易性金融资产、结构性存款时，把该部分进入投资类资产，其余留在经营类资产 |

附注子项两年金额相加必须等于主表该科目。对不上就不要写入简化表。

## 生产资产

生产资产只用于简化表之后的结构指标，不是第四个重分类大类，也不改写简化表。

```text
生产资产 = 生产类资产 - 商誉 - (无形资产 - 土地使用权账面价值)
```

相比生产类资产，少了商誉和土地使用权以外的其他无形资产。扣掉的只有商誉，以及知识产权、软件、特许经营权等非土地无形资产。使用权资产、长期待摊费用、购建预付款留在生产资产里。

土地使用权取合并附注「无形资产」里的年末、年初账面价值。固定资产附注没有土地时，不要把房屋建筑物当成土地，也不要在固定资产里再找一遍土地。没有土地使用权行时，土地按 0，并写明没有土地。

## 结构分析

### 1. 负债同比变动

先看三类负债，再看类内科目。类内科目大幅对冲时，类别合计可以不大，仍然要拆开看。

变动较大：

- 类别变动率 ≥ 30%，或变动金额 ≥ 10 亿元
- 类内科目变动率 ≥ 30% 且变动金额 ≥ 1 亿元，或变动金额 ≥ 10 亿元

对每一项变动较大的类别和科目：

1. 读合并附注里的同名科目。附注表落在标题后的相邻小节时，连同标题含「续」的下一段一起读
2. 读管理层讨论「资产及负债状况分析」里的重大变动说明
3. 附注只有余额或增减表、没有文字原因时，允许再读这几处做交叉核对，仍然只读索引行号：
   - 现金流量表：取得借款收到的现金、偿还债务支付的现金、支付的各项税费、支付给职工以及为职工支付的现金
   - 所得税费用附注：只在应交企业所得税被标出时读。看当期所得税费用和利润总额

原因怎么写：

- 附注写了原因，或给了能直接解释重分类的到期日、款项性质和金额：写原因，引用附注项目，不示警
- 附注没有一句话说明原因，但增减表、到期日或上述现金流数字能把余额变动对上：写成「附注无文字说明，数字可以交叉核对」，不升格为示警
- 附注和重大变动说明都没有原因，数字也解释不了这项变动：必须写 **示警**，并写明附注实际写了什么
- 重大变动说明写成「无重大变动」或留空，但金额已经达到上面的变动标准：单独 **示警**，指出披露与金额不符

融资性负债内部的常见对冲是长期借款下降、一年内到期的长期借款上升。到期日能解释重分类。借款总额的净增加用取得借款减偿还债务核对。质押或信用借款单独大幅增减、附注只写合同条款时，仍然示警。

### 2. 有息负债率

```text
有息负债 = 融资性负债
有息负债率 = 融资性负债 / 资产总计
```

融资性负债已经包含短期借款、长期借款、应付债券、一年内到期的借款和债券、交易性金融负债、衍生金融负债。租赁负债留在经营性负债，不并入有息负债。

有息负债率大于 60%：额外 **示警**。有息负债为 0 时，比率写「无有息负债」，不要做除法。

同时计算：

```text
货币资金 / 有息负债
```

有息负债为 0 时同样不要做除法。这个比值只报告，不另设示警线。

### 3. 生产资产 / 总资产

按上一节「生产资产」计算，两年都算。列出生产资产的构成，并写明土地使用权的账面价值和附注位置。

### 4. 应收 / 总资产

```text
应收 = 带「应收」的科目合计 - 银行承兑汇票
```

计入带「应收」的科目：

- 主表科目名含「应收」的全部账面价值，包括应收票据、应收账款、应收款项融资、其他应收款、长期应收款、应收利息、应收股利
- 一年内到期的非流动资产中，附注确认属于长期应收款的部分

银行承兑汇票只减两类：

- 应收票据附注中的银行承兑汇票账面价值
- 应收款项融资附注中的银行承兑汇票

财务公司承兑汇票、商业承兑汇票、应收账款债权凭证不减。

应收 / 总资产超过 30%：额外 **提醒**。主口径把一年内到期的长期应收款算进应收。另给一列不含该项的结果。任一口径超过 30% 都要提醒，并写明是哪一口径、哪一年。本年降到 30% 以下、上年超过 30% 时，两年都写出来。

### 5. 输出

放在简化表和明细表之后，单独成节。必须包含：

1. 变动较大的负债类别和类内科目，两年金额、变动额、变动率
2. 每一项的附注原因；找不到原因的项用「示警」标出，并摘附注原文在说什么
3. 四行指标：有息负债率、生产资产/总资产、应收/总资产、货币资金/有息负债。写明是否触发 60% 或 30%
4. 生产资产构成，以及土地使用权从哪条附注取出
5. 应收的加总和银行承兑汇票的扣除明细

不要把母公司报表的同名科目混进这些比率。
