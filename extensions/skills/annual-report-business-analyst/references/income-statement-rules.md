# 合并利润表简化口径

只简化合并利润表。母公司利润表不使用。金额以主表为准。附注只解释主表合计，明细两年相加必须等于主表该行，对不上就不要写进简化表。

一般企业利润表的法定小计只有营业利润、利润总额、净利润。毛利和经营利润是分析层，不单列。

## 逐级利润

主表科目是营业收入，不是主营业务收入。附注里的主营业务和其他业务已经合在营业收入里，瀑布不再单列。

```text
毛利 = 营业收入 - 营业成本
```

毛利不减税金及附加。主表没有这一行。

```text
费用 = 销售费用 + 管理费用 + 研发费用
经营利润 = 毛利 - 税金及附加 - 费用
```

经营利润是分析口径。销售费用、管理费用、研发费用在简化瀑布、色块恒等式和两侧金额里合并为「费用」一行，不分别减。三项来源金额列在费用行下，两年分别相加必须等于费用。报表没有研发费用这一行时，按 0，并写明费用未含单列研发费用。财务费用不并进费用，先不减。

```text
减值损失 = 信用减值损失 + 资产减值损失
营业利润 = 经营利润
         - 财务费用
         + 其他收益
         + 投资收益
         + 净敞口套期收益
         + 公允价值变动收益
         + 减值损失
         + 资产处置收益
```

减值损失按主表符号相加，简化瀑布、色块恒等式和两侧金额里只列这一行。主表上名称含「减值损失」的科目都并进这一行；没有的按 0，并写明。来源金额列在减值损失行下，两年分别相加必须等于这一行。公允价值变动收益、资产处置收益不并进减值损失。

营业利润是法定小计，必须与主表一致。上面的损失按主表符号相加：主表写在「加」项里、用负数表示损失。财务费用为负数时，表示利息和汇兑轧差后的净收益；这一步减的是主表原数，等于把净收益加回。利息收入减利息支出不等于财务费用，差额在汇兑、资本化和其他，明细不能代替合计。

「其中：利息费用」「其中：利息收入」「其中：对联营企业和合营企业的投资收益」是备查，不重复加进营业利润。以摊余成本计量的金融资产终止确认收益若已包含在投资收益中，也不重复加；只有把它单列进去之后，复原的营业利润才与主表一致时，才作为独立加项。

```text
利润总额 = 营业利润 + 营业外收入 - 营业外支出
净利润 = 利润总额 - 所得税费用
```

利润总额是法定税前利润。所得税费用包含当期所得税、递延所得税和汇算清缴差异，不是实缴税金。

净利润再拆成归属于母公司所有者的净利润和少数股东损益。拆分不重复加进瀑布。持续经营净利润、终止经营净利润是分类，不进入计算。其他综合收益、综合收益总额、每股收益不进入这条链。

不设「经常性净利润」这一层。财务费用、投资收益、日常经营相关的政府补助已经在营业利润内部。营业利润到利润总额只差营业外收支。扣非归母净利润放在净利润之后：

```text
扣非归母净利润 = 归属于母公司所有者的净利润 - 非经常性损益合计
```

非经常性损益取自年报「非经常性损益」合计，该合计已经扣除所得税影响额和少数股东权益影响额。它是税后、归母口径。

## 最终恒等式

毛利、经营利润、营业利润、利润总额是中间余数，不进入两侧。

报表符号版，每一项按主表原数代入，加项里的损失保持负数：

```text
营业收入 - 营业成本 - 税金及附加 - 费用 - 财务费用
+ 其他收益 + 投资收益 + 净敞口套期收益 + 公允价值变动收益
+ 减值损失 + 资产处置收益
+ 营业外收入 - 营业外支出 - 所得税费用 - 净利润 = 0
```

两侧对照版。费用是左侧的一行，金额为销售费用、管理费用、研发费用之和，不把这三项分列。财务费用仍单独留在左侧，沿用主表符号，不取反、不改称财务净收益，也不并进费用。减值损失也是左侧的一行，以损失为正：信用减值损失、资产减值损失先各自换算（主表「加」项里的负数取反；若报表把减值放在「减」项且损失为正，直接用这个正数），再相加，不把这两项分列。公允价值变动收益、资产处置收益、净敞口套期收益留在右侧，损失为负，不并进减值损失。

```text
左侧 = 营业成本 + 税金及附加 + 费用 + 财务费用
     + 减值损失
     + 营业外支出 + 所得税费用 + 净利润

右侧 = 营业收入 + 其他收益 + 投资收益 + 净敞口套期收益
     + 公允价值变动收益 + 资产处置收益 + 营业外收入
```

左侧合计必须等于右侧合计。配平用元。亿元用于下面的色块表和瀑布展示，回加可能与小计差 0.01，个别步骤可能差 0.02。

主表在营业利润之前还有上面没点名的加减项时，按它所在的「加」或「减」位置放进复原公式，并在简化表里单列。不要为了配平去改主表金额。

## 色块表

配平之后、简化瀑布之前，写两年并排的色块表。每年一张 HTML 表。左右两列分别是恒等式的左侧和右侧，等高、等宽、中间不留缝。格子高度和该侧金额的绝对值成正比。金额为 0 的科目不占格子。

科目用简化合并项。费用是一格，减值损失是一格。不要拆回销售费用、管理费用、研发费用，也不要拆回信用减值损失、资产减值损失。不要用附图里的日本科目名：不写主营业务收入、营业外成本、特别损失、特别收入、法人税等、当期净利润。

左侧自上而下：营业成本、税金及附加、费用、财务费用、减值损失、营业外支出、所得税费用、净利润。右侧自上而下：营业收入、其他收益、投资收益、净敞口套期收益、公允价值变动收益、资产处置收益、营业外收入。主表多出来的加减项，按它所在的一侧插进这个顺序。

样式：成本费用块背景 `#6a727a`、文字 `#1a1a1a`；净利润块背景 `#e36f24`、文字 `#1a1a1a`；右侧正值收入块背景 `#ef8b45`、文字 `#1a1a1a`。文字水平垂直居中。科目和亿元金额写在同一行，中间空一格，例如「营业成本 496.37」。不要用换行把金额放到下一行。格子加 `white-space:nowrap`，避免窄列里自动折成两行。块与块之间留 2px 白线。财务费用为净收益、减值损失为净转回、右侧科目为净损失时，仍留在原来一侧，高度按绝对值，背景 `#f7f4ef`、文字 `#3d3832`、边框 `1px dashed #c4bbb2`。

左右格子数量不同，不要做成逐行对齐的表。外层 table 只有一行两列，列高都是 640px，`border-collapse:collapse`，`table-layout:fixed`。每个 `td` 里放一个等高的纵向 flex。格子的 `flex-grow` 取该格亿元绝对值。过矮放不下一行字的格子，最短约 22px，剩下的列高再按金额分配。色块用亿元，和按元配平的合计可能差 0.01。不要用 Python 生成这段 HTML。

```html
<div style="display:flex;gap:24px;align-items:flex-start;">
  <div style="flex:1;min-width:280px;">
    <div style="font-weight:700;margin:0 0 8px;">年份</div>
    <table style="width:100%;height:640px;border-collapse:collapse;table-layout:fixed;">
      <tr>
        <td style="width:50%;height:640px;padding:0;vertical-align:top;">
          <div style="display:flex;flex-direction:column;height:100%;gap:2px;background:#fff;">
            <div style="flex:496.37 1 0;min-height:22px;background:#6a727a;color:#1a1a1a;display:flex;align-items:center;justify-content:center;text-align:center;font-weight:600;line-height:1.35;white-space:nowrap;">营业成本 496.37</div>
            <div style="flex:151.56 1 0;min-height:22px;background:#e36f24;color:#1a1a1a;display:flex;align-items:center;justify-content:center;text-align:center;font-weight:600;line-height:1.35;white-space:nowrap;">净利润 151.56</div>
          </div>
        </td>
        <td style="width:50%;height:640px;padding:0;vertical-align:top;">
          <div style="display:flex;flex-direction:column;height:100%;gap:2px;background:#fff;">
            <div style="flex:893.40 1 0;min-height:22px;background:#ef8b45;color:#1a1a1a;display:flex;align-items:center;justify-content:center;text-align:center;font-weight:600;line-height:1.35;white-space:nowrap;">营业收入 893.40</div>
          </div>
        </td>
      </tr>
    </table>
  </div>
</div>
```

上例只说明结构。写出时把两侧实际科目按上面的顺序放全，`flex` 的权重换成该格当年的亿元绝对值。

## 附注

简化表根据读到的合并利润表直接生成。瀑布、法定小计和恒等式必须与主表复原一致。对不上就不要写简化表，也不要改主表金额去配平。

附注不参与主表合计。需要展开时，只按索引行号读这些合并附注：营业收入和营业成本、税金及附加、财务费用、其他收益、投资收益、公允价值变动收益、信用减值损失、资产减值损失、营业外收入、营业外支出、所得税费用。信用减值损失和资产减值损失附注仍分别读，各自合计必须等于主表对应行，用来解释合并后的减值损失，不在瀑布和恒等式里分列。附注表落在标题后的相邻小节时，连同标题含「续」的下一段一起读。明细合计必须等于主表该行。对不上就写示警，不要把对不上的明细写进简化表。
