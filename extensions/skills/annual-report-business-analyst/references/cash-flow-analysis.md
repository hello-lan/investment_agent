# 合并现金流量表分析口径

只分析合并现金流量表。母公司现金流量表不使用。金额以主表为准。附注只用来剔除滚动项和取得分红付现，不改主表净额。

比值用元计算，至少保留两位小数。画像里的净额可以另附亿元，由元除以 1 亿、保留两位小数。

某一类净额为 0 时，不记成正，也不记成负。八种画像对不上，写明净额为 0，并指出只差这一格的相邻类型，不硬套名称。

## 勾稽

按元、保留到分，差额必须是 0.00。

```text
经营活动现金流入小计 - 经营活动现金流出小计 = 经营活动产生的现金流量净额
投资活动现金流入小计 - 投资活动现金流出小计 = 投资活动产生的现金流量净额
筹资活动现金流入小计 - 筹资活动现金流出小计 = 筹资活动产生的现金流量净额
三类净额 + 汇率变动对现金及现金等价物的影响 = 现金及现金等价物净增加额
年初现金及现金等价物余额 + 现金及现金等价物净增加额 = 年末现金及现金等价物余额
```

主表没有汇率变动这一行时，按 0，并写明。对不上就停，改写 `{base_dir}/<code>/<report>.cash-flow-analysis.review.md`。`base_dir` 以 `SKILL.md` 开头的定义为准。

## 五个指标

本年和上年都算。净利润含金量、销售收现比缺营业收入、净利润或对应现金行时，该年写「无法计算」并说明缺哪一行。分母为 0 时同样写「无法计算」。

### 净利润含金量

```text
净利润含金量 = 经营活动产生的现金流量净额 / 净利润
```

净利润用合并利润表的「净利润」，不用「归属于母公司所有者的净利润」。经营现金流是合并口径。

### 销售收现比

```text
销售收现比 = 销售商品、提供劳务收到的现金 / 营业收入
```

营业收入用合并利润表的「营业收入」，不用主营业务收入。销售收现含增值税，营业收入不含税，略高于 1 仍属正常收现。写出这个口径，不要把高于 1 本身写成异常。

### 投资现金流出 / 投资现金流入

同时给三列。后一列在前一列的基础上再剔，不从原始数里重复减。

```text
比值 = 投资活动现金流出小计 / 投资活动现金流入小计
```

1. 报表原值：主表两个小计直接相除。
2. 剔除理财后：从流出和流入里同时减去委托理财、银行理财的滚动买入和到期赎回。年报写「不存在委托理财」，或可剔除金额为 0：写明剔除额为 0，比值与原值相同。
3. 再剔除同类对滚后：附注在两侧列出同一类工具的大额对滚时，再从第 2 列的流入、流出里减去该工具两侧的金额，单列这一列。典型是「收回投资收到的现金」和「投资支付的现金」里的远期外汇合约；列在「收到其他与投资活动有关的现金」和「支付其他与投资活动有关的现金」两侧的同一工具同样处理。附注没有这种对滚：写明未列示，不另算，不编造剔除额。

理财和对滚只从下列行里找，并且必须附注写明了工具名称和金额：

- 收回投资收到的现金
- 投资支付的现金
- 收到其他与投资活动有关的现金
- 支付其他与投资活动有关的现金

下列项目不剔除，即使金额很大：

- 购建固定资产、无形资产和其他长期资产支付的现金
- 股权投资支付的现金
- 取得子公司及其他营业单位支付的现金净额
- 处置固定资产、无形资产和其他长期资产收回的现金净额
- 取得投资收益收到的现金

每一列都写出：剔除了什么、流入侧金额、流出侧金额。最后一列再写出剩余流入和剩余流出的构成，构成相加必须等于剔除后的小计。剔除后流入为 0：比值写「无法计算（流入为 0）」，并保留流出金额。

剔除只用于这个比值，以及奶牛型检验里的投资现金流出。不回改主表上的投资活动现金流量净额，画像符号仍用主表净额。

### 现金及现金等价物净增加额是否大于 0

```text
现金及现金等价物净增加额 > 0
```

用主表「现金及现金等价物净增加额」，不从三类净额重算。写出金额，并写「是」或「否」。大于 0 写「是」。小于 0 或等于 0 写「否」；等于 0 时写明净额为 0。主表没有这一行：该年写「无法计算」。

### 期末现金及现金等价物余额 / 有息负债

```text
比值 = 期末现金及现金等价物余额 / 有息负债
```

分子用主表「期末现金及现金等价物余额」。主表写成「年末现金及现金等价物余额」时，用那一行。不用资产负债表的货币资金。

分母是同期合并资产负债表上的有息负债，口径与融资性负债相同：

```text
有息负债 = 短期借款
        + 交易性金融负债
        + 衍生金融负债
        + 长期借款
        + 应付债券
        + 一年内到期的长期借款
        + 一年内到期的应付债券
```

本年用现金流量表本年期末现金、资产负债表期末有息负债。上年用现金流量表上年期末现金、资产负债表上年年末有息负债。主表没有的科目按 0，并写明。

一年内到期的非流动负债必须按合并附注拆开，只加借款和债券。租赁负债、一年内到期的租赁负债、长期应付款、预计负债不计入。附注拆不开，或子项加总对不上主表该科目：该年写「无法计算」，并写明差在哪里。不要把一年内到期的非流动负债整笔加进分母。这一行主表没有或为 0：不必读附注，借款和债券按 0。

列出计入的科目和金额，相加必须等于分母。有息负债为 0：写「无法计算（有息负债为 0）」。比值至少保留两位小数。只报告比值，不另设通过线。不做资产负债表重分类，不改写简化表。

## 八种画像

用主表三个净额的正负。正记「+」，负记「-」，顺序是经营、投资、筹资。本年和上年都列。年报通常只有这两列。写明：一两年同号不能认定秉性，要多年一致才算。

关注要点据唐朝《手把手教你读财报》的公开转述整理。执行时只用下面这一段，不重新检索网页。只写当年符号对应的那一型，不把八型全文抄进结果。

经营净额为正：

| 符号 | 名称 | 关注要点 |
| --- | --- | --- |
| +++ | 妖精型 | 主业在收钱、投资也在收钱，却还要筹资，不合常理。要么即将开展大规模投资、正在筹本钱，这时改看蛮牛型：项目前景，以及经营现金和筹资现金能否撑到项目产生现金。遍查没有可核验的投资计划，则有把上市公司当壳子筹资的可能，远离。 |
| ++- | 老母鸡型 | 经营净流入说明主业良性。投资净流入要分清是以前投资的股利、利息，还是变卖家当；变卖固定资产或其他长期资产是衰败信号。筹资净流出是还债、分红或回购。投资流入不是卖家当，且经营流入加投资流入盖得住筹资流出时，企业处于收获期，成长已是过去式，近似稳定产现金的债券。关注低市盈率、高股息。 |
| +-+ | 蛮牛型 | 经营挣的钱，加上借债或出让股权筹来的钱，一起投进新项目。先看投资项目前景。再看经营现金流入和筹资现金流入能否撑到项目产生现金。筹资主要是借债：体现对项目回报高于利息的信心，但对现有股东更负责的同时，债要还，必须看债务期限和金额，避免资金链断裂。筹资主要是出让股权：要问是不是借不到钱才低价出让，以及管理层对项目收益率是否有足够信心。 |
| +-- | 奶牛型 | 靠经营现金扩张，同时还债或回报股东。关键是下面的差值是否为正。为正，是优质成长奶牛。为负，可能滑向蛮牛型，改看蛮牛型的要点。无论正负，都要看所投项目会不会失败。做下面的数字检验。 |

经营净额为负。A 股语境下，这通常不是尚未盈利的初创，而是主业不造血。原则上排除，仍要写清投资流入是分红还是变卖家当。项目文档把这四型笼统记成大出血、赌徒、混吃等死、骗吃骗喝，没有逐项对应符号。下面的对应按公开转述：-++ 骗吃骗喝，-+- 混吃等死，--+ 赌徒，--- 大出血。

| 符号 | 名称 | 关注要点 |
| --- | --- | --- |
| -++ | 骗吃骗喝型 | 经营失血，投资和筹资都是净流入，说明还能从市场上筹到钱。投资流入若靠变卖家当，是在败家的同时借钱。投资流入若是被投企业分红，经营符号实际上应看成正，三正变成妖精型，改看妖精型。 |
| -+- | 混吃等死型 | 经营失血，投资净流入，筹资净流出。投资流入若是变卖家当，就是吃老本还在还债。若是被投企业分红，相当于整容的老母鸡，但要先堵住经营失血；现金及现金等价物净增加额必须为正，否则是坐吃山空。 |
| --+ | 赌徒型 | 经营失血，还在投资，钱来自筹资。用别人的钱赌项目，主业不造血。看项目能否在资金断裂前转正。借债要看期限和金额；股权筹资要问是不是借不到钱。 |
| --- | 大出血型 | 经营、投资、筹资同时净流出，靠存量现金硬撑。远离。 |

只有奶牛型做下面的差值检验。其他类型只写上表里的关注要点，不套这个公式。

## 奶牛型数字检验

投资现金流出用「再剔除同类对滚后」的流出；没有对滚时，用「剔除理财后」的流出。主表投资净额的符号不变。

```text
差值 = 经营活动产生的现金流量净额
     - 剔除滚动项后的投资活动现金流出
     - (筹资活动现金流出小计 - 年内现金分红)
```

年内现金分红只取筹资活动负债变动表里「应付股利」的现金变动。现金变动为负，表示付现，取绝对值。这个表不在已读的「现金流量表项目」及其「续」里：写明分红和利息未拆开，检验未完成。不要用利润表的利息费用去拆「分配股利、利润或偿付利息支付的现金」。利息费用是权责发生制，不是付现利息。

差值为正：写可持续。差值为负：写可能滑向蛮牛型。

同时写两笔比较，不代入差值：

- 购建固定资产、无形资产和其他长期资产支付的现金是否高于经营活动现金流量净额。高于，则是资本开支持续靠外部资金维持
- 取得借款收到的现金与偿还债务支付的现金孰大。偿还明显大于取得，要对照附注看是主动还债，还是借新还旧接不上

附注若在「支付其他与筹资活动有关的现金」里单列回购，写出金额。回购不代入差值。
