# Terminology and metric conventions

这个文件用于统一 skill 内部使用的**术语口径、公式口径、经验阈值与修正规则**。

目的有两个：
1. 避免模型把少数“非标准教材口径”按自己理解随意改写；
2. 当输出里出现特定术语时，让判断、比较、阈值和公式保持一致。

使用原则：
- **标准财务指标**与**经验型分析口径**分开对待，不要混写成同一类结论。
- 若同一主题同时存在“通用口径”和“工程口径”，默认优先使用**通用/分析口径**；只有在需要批量抽取、字段归集或自动化计算时，才切到**工程口径**。
- 经验阈值只用于**预警和排雷**，不是硬性会计准则。
- 如果公司属于强周期、地产、金融、重资产、票据结算占比高等场景，解释时要主动写明“该口径需谨慎使用”。

## 1. 债务、偿债与流动性口径

### 现金债务比
**标准口径**：
- `现金债务比 = 现金及现金等价物 ÷ 有息负债`

**判断参考**：
- `≥ 1` 较稳健

**可放宽口径**：
- `(现金及现金等价物 + 可迅速变现的金融资产净值) ÷ 有息负债`
- `(现金及现金等价物 + 可迅速变现的金融资产净值) ÷ 一年内到期的有息负债`

**使用说明**：
- “可迅速变现的金融资产”可包含交易性金融资产、银票等。
- 保守分析时，优先看是否能覆盖**全部有息负债**，而不只是短债。

### 货币资金 / 有息负债
- `货币资金 ÷ 有息负债`

**可放宽口径**：
- `(货币资金 + 可随时变现的交易性金融资产 + 应收票据) ÷ 有息负债`

**使用说明**：
- 这个比值主要用于看偿债能力和账上现金是否站得住。
- 适合做历史比较，不必强求同行比较。

### 有息负债率
- `有息负债率 = 有息负债 ÷ 总资产`

**判断参考**：
- 经验上，`> 60%` 可视为偏激进，应提高警惕。

**使用说明**：
- 适合与同时期、同行业公司比较，不宜跨行业硬比。

### 有息负债（工程口径）
在需要批量抽取时，可用：
- `有息负债 = 短期借款 + 长期借款 + 应付债券 + 一年内到期非流动负债 + 长期应付款（融资租赁部分）`

### 流动比率与速动比率
- `流动比率 = 流动资产 ÷ 流动负债`
- `速动比率 = (流动资产 - 存货) ÷ 流动负债`

**经验参考**：
- 流动比率一般在 `2` 左右
- 速动比率一般在 `1` 左右

**使用说明**：
- 这些值只能作一般参考，必须结合行业特征解释。

## 2. 资产结构与资本配置口径

### 生产资产占总资产
**分析口径**：
- `生产资产占比 = 生产资产 ÷ 总资产`

**生产资产范围**：
- 固定资产
- 在建工程
- 工程物资
- 无形资产里的土地

**特别说明**：
- 这里的“生产资产”**不含商誉**，也**不含除土地之外的其他无形资产**。
- 这是本 skill 里需要特别统一的口径，不要自行把商誉并进去。

### 生产资产占比（工程口径）
若做字段抽取，可用：
- `(固定资产 + 在建工程 + 无形资产 + 长期待摊费用) ÷ 总资产`

**说明**：
- 这是为了自动化更容易落地，不等同于上面的分析口径；两者不要混算。

### 轻资产 / 重资产判断口径
- `轻重判断比值 = 当年税前利润总额 ÷ 生产资产`

**判断参考**：
- 若该比值显著高于社会平均资本回报率，则更偏“轻公司”
- 反之则更偏“重公司”

**说明**：
- 这是经验判断法，不是会计准则定义，但分子分母明确，可用于实务分析。

### 应收占总资产
- `应收占比 = 应收款 ÷ 总资产`

**应收款范围**：
- `资产负债表所有带“应收”两个字的科目数字总和 - 银行承兑汇票金额`

**补充观察口径**：
- `应收账款相当于几个月收入 = 应收账款余额 ÷ 月均营业收入`

**说明**：
- 这是经验口径，不完全等同于正式会计分类。
- 剔除银行承兑汇票，是为了更聚焦信用风险与回款质量。

### 非主业资产占总资产
- `非主业资产占比 = 非主业资产 ÷ 总资产`

**常见非主业资产**：
- 交易性金融资产
- 可供出售金融资产
- 持有至到期投资
- 银行理财产品
- 投资性房地产

### 非主业资产占比（工程口径）
可用于自动化归集：
- `(交易性金融资产 + 投资性房地产 + 长期股权投资 + 可供出售金融资产等) ÷ 总资产`

**说明**：
- 分析口径关注“公司是否把注意力放在主业之外”；工程口径更偏批量抽取。

## 3. 现金流肖像与现金流质量口径

### 现金流肖像
按三大现金流净额正负分类：
- 经营活动现金流净额：正 / 负
- 投资活动现金流净额：正 / 负
- 筹资活动现金流净额：正 / 负

**主要类型**：
- 妖精型 = `+++`
- 老母鸡型 = `++-`
- 蛮牛型 = `+-+`
- 奶牛型 = `+--`
- 赌徒型 = `--+`

**特别说明**：
- `老母鸡型` 是 `++-`
- `奶牛型` 是 `+--`
- 这两个符号组**不能写成同一类**。

### 奶牛型企业的可持续性判断
针对 `+--` 奶牛型：
- `经营活动现金流入量 - 投资活动现金流出 - 不包括分红在内的筹资活动现金流出`

**判断方法**：
- 若差值为正：更接近可持续的优质奶牛型
- 若差值为负：可能随时转向 `+-+` 的蛮牛型特征

### 净利润含金量
- `净利润含金量 = 经营现金流净额 ÷ 净利润`

**判断参考**：
- 连续数年 `> 1`：通常较好
- 连续数年远小于 `1`：需重点解释原因

**说明**：
- 折旧较高行业、房地产行业不宜机械套这个阈值。

### 自由现金流
- `自由现金流 = 经营活动现金流净额 - 购建固定资产、无形资产和其他长期资产支付的现金`

**说明**：
- 用于看企业在维持和扩张资本开支后，还剩多少可自由支配现金。

## 4. 收现、票据与收入还原口径

### 销售收现比
- `销售收现比 = 销售商品、提供劳务收到的现金 ÷ 营业收入`

**快速判断参考**：
- 持续 `≥ 1`：通常可认为收现情况较好
- 若显著 `< 1`：需警惕收入真实性、收款节奏变化或信用政策放松

**经验预警线补充**：
- A 股含增值税口径下，理论上应 `> 1.13`
- 这是经验线，不是硬规则。使用时要先确认是否采用含税还原口径。

### 票据背书修正后的收现核对
当公司大量收到票据，并用于背书转让、贴现、抵押、保理时：

**修正规则**：
1. 在附注中搜索“背书”
2. 查找“使用票据背书转让购买商品或劳务”的金额
3. 查找“使用票据背书转让购买固定资产及无形资产”的金额
4. 将上述金额加回后，再核对销售收现与营业收入是否匹配

**说明**：
- 这是一条修正规则，不是单一静态公式。
- 若加回背书因素后仍偏差较大，要继续追问解释。

### 销售收现还原公式
- `销售商品、提供劳务收到的现金 ≈ 含增值税营业收入 +（应收票据期初账面余额 - 期末账面余额 - 本期已贴现票据）+（应收账款期初账面余额 - 期末账面余额）+（预收款项期末账面余额 - 期初账面余额）- 非现金抵账 + 收回已核销坏账`

**配套口径**：
- `含增值税营业收入 = 营业收入 ×（1 + 增值税税率）`
- `账面余额 = 账面价值 + 减值准备`

### 隐藏（释放）收入 / 实际收入还原
- `当年实际收入 = 销售收到的现金 + 应收款项的增加`
- `隐藏（释放）收入 = 当年实际收入 ÷（1 + 所得税率） - 报表展示收入`

**说明**：
- 这是偏进阶的还原口径，使用时必须同步核对税率、坏账准备和票据因素。

### 合同负债 / 预收款还原真实营收
- 使用预收款：`真实营收 = 期间营收 + 期间预收款增加 ÷（1 + 增值税率）`
- 使用合同负债：`真实营收 = 期间营收 + 期间合同负债增加`

**特别说明**：
- 合同负债不包含增值税
- 预收款口径需要先剔除增值税影响

## 5. 周转、效率与盈利能力口径

### 应收账款周转率
- `应收账款周转率 = 营业收入 ÷ 应收账款平均余额`

**补充说明**：
- 可做历史对比与同业对比
- 工程化实务中，可把商票余额并入应收账款余额

### 应收周转天数
- `应收周转天数 = 应收账款平均余额 ÷ 营业收入 × 365`

### 存货周转率
- `存货周转率 = 营业成本 ÷ 存货平均余额`

### 存货周转天数
- `存货周转天数 = 存货平均余额 ÷ 营业成本 × 365`

### 固定资产周转率
- `固定资产周转率 = 营业收入 ÷ 固定资产净值`

### 总资产周转率
- `总资产周转率 = 营业收入 ÷ 平均总资产`

### 毛利率
- `毛利率 =（主营业务收入 - 营业成本）÷ 主营业务收入`

### 综合费用率
- `费用率 = 三费 ÷ 营业总收入`

**保守口径补充**：
- 若财务费用为正：按三费加总
- 若财务费用为负：只用销售费用 + 管理费用

### 分项费用率
- 销售费用率 = `销售费用 ÷ 营业收入`
- 管理费用率 = `管理费用 ÷ 营业收入`
- 研发费用率 = `研发费用 ÷ 营业收入`
- 财务费用率 = `财务费用 ÷ 营业收入`

### 营业利润率
- `营业利润率 = 营业利润 ÷ 营业收入`

### 净利率
- `净利率 = 净利润 ÷ 营业收入`

### 有效税率
- `有效税率 = 所得税费用 ÷ 利润总额`

**说明**：
- 若利润总额为负或接近 0，这个指标通常不具备比较意义，应单独说明。

### ROE
- `ROE = 净利润 ÷ 平均净资产`

**经验参考**：
- 连续数年 `> 15%` 可视为优秀公司特征之一

### 总资产收益率
- `总资产收益率 = 净利润 ÷ 平均总资产`

### 杜邦分析
- `ROE = 净利率 × 总资产周转率 × 杠杆系数`

**说明**：
- 用于拆解 ROE 是来自利润率、周转效率还是杠杆放大。

## 6. 风险质量比值与常用预警线

### 风险质量比值
- `应收 / 营收 = 应收账款 ÷ 营业收入`
- `商誉 / 净资产 = 商誉 ÷ 归母净资产`
- `非经常性损益占比 = 非经常性损益 ÷ 归母净利润`
- `存货与成本增速差 = 存货增速 - 营业成本增速`

### 常用经验预警线
- 现金净含量：连续多年 `> 1` 较好；连续 `> 1.2` 较优；连续 3 年以上 `< 1` 为高优先级风险信号
- 受限资金 / 货币资金 `> 30%`：实际可动用资金质量偏弱
- 利息收入 / 货币资金均值 `< 0.5%`：需警惕货币资金真实性或使用受限
- 连续 2 年应收增幅 - 营收增幅 `> 10%`：收入质量恶化信号
- 存货周转天数同比增加 `> 30 天`：需重点关注
- 商誉 / 净资产 `> 30%`：减值风险较高
- 非经常性损益 / 净利润 `> 30%`：利润质量偏弱
- 有效税率 `< 10%` 且无合理解释：需警惕

**说明**：
- 这些阈值都属于经验型预警线，用来排序风险优先级，不用来替代完整判断。

## 7. 经营现金流间接法中的方向性调整

### 经营性应收 / 经营性应付对经营现金流的调整方向
- 经营性应收减少：对经营现金流为正向影响，需加回
- 经营性应付增加：对经营现金流为正向影响，需加回

**说明**：
- 这里强调的是调整逻辑与方向，不额外扩展自定义科目清单。

## 8. 术语使用提醒

以下术语在本 skill 中都应按本文件执行，不要自行改写：
- 现金债务比
- 有息负债率
- 生产资产 / 生产资产占比
- 轻资产 / 重资产判断
- 应收占总资产
- 非主业资产占比
- 现金流肖像（尤其是老母鸡型、奶牛型）
- 销售收现比
- 票据背书修正
- 净利润含金量
- 有效税率
- 自由现金流
- 杜邦分析

如果输出中使用这些术语，优先按“**公式 / 范围 / 阈值 / 适用条件**”四件事来解释，避免只报一个名字不给定义。
