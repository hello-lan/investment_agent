# 排雷必查覆盖

本文件是排雷的**下限清单**。P0 读完后，逐组填写状态，再对照 `references/forensic-rules.md`。

每一组只写三种状态之一：

- **命中**：写清事实数字，并引用 `R0xx`；没有编号的组合信号写「规则外」
- **未触发**：已看到对应证据，且未达到触发条件
- **待验证**：这一组的关键节点还没读到，写明缺哪一节

规则表是下限。走完各组后，再看有没有规则外但仍实质重要的信号。未触发阈值但趋势已经变差（质押比例连续攀升、账龄逐年迁到 1 年以上），也要写入关注，不能因为没过线就省略。

本技能默认只分析用户给定的一份年报。规则写「连续 N 年」而手边只有本年时，状态可标命中或倾向，并注明「单年观察，连续性待验证」。不要猜测其他年份的路径。

专题文件只在某一组命中或证据不够时再读，不为了刷清单去通读附注。

---

## A. 硬伤

优先节点：`财务报告-审计报告`、重要提示、`第四节 公司治理`、`第六节 重要事项`、`第七节 股份变动及股东情况`。

| 查什么 | 触发 | 节点 |
|--------|------|------|
| 审计意见 | 保留 / 无法表示 / 否定 → `R019`。带强调事项或持续经营重大不确定性时，即使仍是无保留，也列入关注 | 审计报告、重要提示 |
| 会计师事务所 | 3 年内更换超过 1 次且非强制轮换 → `R020` | 审计报告、公司治理、重要事项 |
| 关键高管 | 财务负责人、董秘、审计负责人、独董在年报前后异常离职或公开异议 | 公司治理 |
| 控股股东质押 | 质押股数 / 持股股数 > 50% → `R021`。未到 50% 但连续攀升也必须列入。写明实控人、持股、质押比例方向、资金用途是否披露 | 股东情况、重要事项 |
| 其他大股东 | 持股 > 5% 的股东质押或冻结（可得时） | 股东情况 |
| 股权冻结 | 存在司法冻结 → `R030` | 股东情况、或有事项 |
| 关联销售或采购 | 关联销售 / 营收 > 30%，或关联采购占比畸高 → `R022`；合并与母公司利润结构不对称可对照 `R026` | 关联方及关联交易、重要事项 |
| 信息披露与监管 | 未按时披露、被立案调查或处罚、频繁会计差错更正 | 重要提示、重要事项 |
| 追溯重述 | 前期差错更正、追溯调整，且原因含糊或发生在业绩承压年份 | 重要会计政策、重要提示 |

硬伤这一组在覆盖表里合成一行：有任一命中就写命中及编号；都看过且没有就写未触发；审计或股东章节没读到就写待验证。

## B. 货币资金

优先节点：合并资产负债表、货币资金附注、借款附注、财务费用。细节见 `references/asset-quality-and-capital-allocation.md`。

| 查什么 | 触发 | 节点 |
|--------|------|------|
| 总额与受限细分 | 列出定期存款及利息、银承/信用证/远期等保证金、其他受限 | 货币资金附注 |
| 受限占比 | 受限资金 / 货币资金 > 30% → `R012` | 货币资金附注 |
| 利息与存款 | 利息收入 / 货币资金均值 < 0.5% → `R011` | 财务费用、货币资金 |
| 有息负债 | 列出有息负债与利息费用；与货币资金对照 | 借款附注、财务费用 |
| 存贷双高 | 货币资金与有息负债同时畸高且解释不足 → `R010` | 货币资金、借款 |
| 穷病 | 货币资金远低于短期有息负债。与存贷双高相反，同样是资金链信号 | 货币资金、一年内到期借款 |

## C. 应收

优先节点：应收账款附注（含账龄、坏账）、合并利润表、主营业务分析。

| 查什么 | 触发 | 节点 |
|--------|------|------|
| 净额与增速差 | 连续 2 年应收增幅 − 营收增幅 > 10% → `R001`；仅本年偏离则注明单年观察 | 应收附注、利润表 |
| 应收 / 营收 | 制造业 > 30% → `R002`；其他行业结合账期 | 应收附注、主要财务指标 |
| 长账龄 | 1 年以上应收金额增幅 > 50% → `R003`。同时写 1 年以内占比 | 账龄附注 |
| 坏账政策与转回 | 当年放松计提 → `R004`；计提金额同比减少 > 30% → `R037`；转回金额占净利润 > 10% → `R038` | 坏账准备、会计政策 |

## D. 存货

优先节点：存货附注、营业成本、主营业务分析。

| 查什么 | 触发 | 节点 |
|--------|------|------|
| 账面与增速 | 存货增幅 − 营收增幅 > 20% → `R005` | 存货附注、利润表 |
| 存货 / 营业成本 | 比值抬升且缺乏产销解释 | 存货、营业成本 |
| 跌价与构成 | 计提比例显著低于库龄恶化 → `R006`；跌价准备 / 存货 < 1% 且周转变慢 → `R036`。列出原材料、在产品、库存商品、发出商品（可得时） | 存货跌价附注 |
| 周转 | 周转天数同比增加 > 30 天 → `R007` | 存货、营业成本 |
| 毛利率 × 周转 | 毛利率上升且存货周转天数延长。即使未触及 `R005` / `R007` 也写入关注（超量生产摊薄固定成本） | 主营业务分析、存货 |

## E. 长期资产与商誉

优先节点：在建工程、固定资产、开发支出、商誉附注、合并范围变更、重大投资说明。

| 查什么 | 触发 | 节点 |
|--------|------|------|
| 在建工程转固 | 超预算约 100% 且超期 1 年不转固 → `R024`；付款对手方关联且工程真实性存疑 → `R034` | 在建工程、关联方 |
| 商誉 | 商誉 / 归母净资产 > 30% → `R008`；业绩承诺不达标但仍不减值 → `R009`。承诺期内精准达标、期后变脸写入规则外 | 商誉减值测试、重要事项 |
| 费用资本化 | 开发支出、长期待摊、在建工程异常堆高，把当期费用推到以后 | 开发支出、长期待摊、会计政策 |
| 固定资产规模 | 固定资产 / 总资产 > 40% 且周转率低于行业 → `R025` | 固定资产附注 |

## F. 利润质量

优先节点：合并利润表、主要财务指标、主营业务分析、非经常性损益说明。

| 查什么 | 触发 | 节点 |
|--------|------|------|
| 毛利率水平 | 明显高于同行约 20 个百分点且无解释 → `R015` | 主营业务、分部 |
| 毛利率波动 | 波动超过 10 个百分点且无解释 → `R032` | 主营业务、成本附注 |
| 费用率 | 营收正增长但费用率下降约 5 个百分点且解释不足 → `R018` | 利润表费用、费用附注 |
| 扣非与非经常 | 非经常性损益 / 净利润 > 30% → `R016`；扣非与净利润差距连续扩大 → `R017` | 主要财务指标 |
| 利润被边缘项目托住 | 主业偏弱，其他业务收入、营业外收益、资产处置收益异常亮眼（规则外） | 利润表、附注 |
| 季度与海外 | Q4 营收占比 > 35% 且无季节性 → `R023`；海外收入 > 50% 且毛利率远高于国内 → `R029`，再看是否小所审计 → `R031` | 主要财务指标、分部、审计报告 |
| 税 | 所得税 / 营业利润 < 10% 且无合规解释 → `R028` | 税项附注 |

## G. 现金流

优先节点：合并现金流量表、现金流量表补充资料。肖像定义以 `references/terminology-and-metric-conventions.md` 为准。

| 查什么 | 触发 | 节点 |
|--------|------|------|
| 经营现金流 / 净利润 | 连续 3 年以上 < 1 → `R013`；仅本年显著偏低则注明单年观察 | 现金流量表 |
| 经营现金流多年为负 | 连续 3 年为负 → `R035`；单年为负写倾向 | 现金流量表 |
| 销售收现比 | 连续偏低 → `R014`。有票据背书时先按术语文件修正再判断 | 现金流量表、应收票据 |
| 自由现金流 | 经营现金流 − 购建固定资产支付的现金。持续为负则资本投入在侵蚀造血 | 现金流量表 |
| 肖像 | 必须写出类型名和三类现金流符号，如奶牛型 `(+--)` | 现金流量表 |
| 筹资大进大出 | 筹资流入与流出均超过经营现金流净额约 2 倍 → `R027` | 现金流量表、借款 |

## H. 联动、规则外组合与结构快照

三表联动至少回答：收入—应收—现金、利润—经营现金流、资本开支—折旧/回报是否闭环。

规则外组合（命中则写入「额外重大发现」，不要因为没有编号就省略）：

| 查什么 | 触发 | 节点 |
|--------|------|------|
| 毛利率升、应收升、应付降 | 竞争力叙事与回款、供应链地位不同向 | 利润表、应收、应付 |
| 商票占比上升 | 结算方式变差，兑付风险高于银票 | 应收票据附注 |
| 预付、其他应收、长期应收 | 大幅增长或长期挂账，可能是资金占用通道 | 对应附注、关联方 |
| 陌生客户、年底冲量 | 突然出现的大客户、新业务、异常定价或年底集中确认 | 收入附注、主营业务 |
| 洗大澡 | 差年集中计提或注销，次年快速恢复，常伴随追溯重述 | 减值、重要提示 |
| 现金流包装 | 经营现金流改善来自保理、客户融资、经营支出重分类，投融资端同步异常 | 现金流量表及补充资料 |
| 募投变更后变脸 | 募投用途反复改，或收购标的承诺期内精准达标、期后业绩变脸 | 重要事项、商誉 |

结构快照（四项数据都够才算，不够就在覆盖表「联动」行注明缺什么，不要为了四项去通读）：

- 生产资产 / 总资产
- 应收 / 总资产
- 现金 / 有息负债
- 非主业资产 / 总资产

口径以 `references/terminology-and-metric-conventions.md` 为准。

## 覆盖表怎么收口

输出时把上面各组收成 8 行（见 `references/output-contract.md`）：硬伤、货币资金、应收、存货、长期资产与商誉、利润质量、现金流肖像、联动。

- 现金流肖像这一行即使未触发规则，也要写出类型名
- 联动这一行覆盖本节的三表闭环、规则外组合；结构快照有数就附在这行后面
- 叙事只展开 3–5 条最重要的雷，其余停在覆盖表里
