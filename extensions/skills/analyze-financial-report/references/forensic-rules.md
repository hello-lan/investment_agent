# Forensic rules (R001–R038)

这个文件是 analyze-financial-report 的**排雷规则库**。

它负责：
1. 提供可引用的规则编号、触发条件与严重度
2. 把命中规则映射到专题知识文件与优先索引节点
3. 约束输出写法：事实数据 + `R0xx` + 风险推断

它**不替代**定向索引阅读。规则用于对照已读章节与附注节点；不要为了“过完全部规则”而全文通读年报。分组必查项（命中 / 未触发 / 待验证）见 `references/mine-coverage.md`。

阈值口径若与 `references/terminology-and-metric-conventions.md` 重叠，以本表触发条件为准做规则引用，公式与术语定义仍以 terminology 文件为准。

---

## How to use

### 先过规则表，再跳出规则表
1. 在完成 P0（必要时 P1）定向阅读后，对照本表逐条检查**已拿到的数据**能否触发
2. 规则表是分析下限，不是上限；规则外但实质重要的信号，写入「额外重大发现」
3. 未读到对应章节/附注时，不要硬套规则；在「待验证」中标明缺什么证据
4. 单项异常不得直接定性造假；优先做三表交叉验证

### 命中写法
每条命中尽量写成：
- **事实数据**：具体数字、同比、占比、章节来源
- **规则依据**：`R0xx`
- **风险推断**：从事实到风险的逻辑链，以及当前判断（已构成明确风险 / 倾向风险 / 仍待验证）

### 专题文件缩写
- `asset` → `references/asset-quality-and-capital-allocation.md`
- `linkage` → `references/liability-profit-cashflow-linkage.md`
- `gov` → `references/governance-and-fraud-signals.md`
- `principles` → `references/analysis-principles.md`
- `term` → `references/terminology-and-metric-conventions.md`

### 优先索引节点（通用）
- 审计：`财务报告-审计报告`
- 指标：`第二节 公司简介和主要财务指标`
- 治理/股东：`第四节 公司治理`、`第七节 股份变动及股东情况`、`第六节 重要事项`
- 主表：合并资产负债表 / 利润表 / 现金流量表
- 附注：`财务报告-合并财务报表项目注释` 下对应科目 children
- 专题：关联方、合并范围变更、承诺及或有事项、日后事项、重要会计政策

## Single-year application notes

本 skill 默认只分析单份 `report_path`：
- 标注“连续 N 年”的规则：若仅有单年数据，仍可计算当期偏离；命中时写清「单年观察，连续性待下一年验证」，判断多用「倾向风险 / 仍待验证」
- 不要为凑“连续多年”去猜测其他年份路径或全文扫描目录

## After the rule pass

对照完规则表后，再通读已加载证据，问：
1. 有没有任何**未落入 R001–R038** 但仍实质重要的信号？
2. 是否存在跨指标联动（如毛利率升 + 存货周转变慢、毛利率升 + 应收升 + 应付降）？
3. 三大前提能否回答：利润是否为真、是否可持续、维持是否需大量资本投入？

规则外重大发现写入输出中的「额外重大发现」；不要因为没有编号就省略。
