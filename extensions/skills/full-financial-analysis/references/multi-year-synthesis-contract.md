# Multi-year synthesis contract

本文件定义 `full-financial-analysis` **步骤 5** 的多年综合报告结构。

输入不是原始年报全文，而是步骤 4 已落盘的各年：
`data/reports/md/{code}/{stem}.analysis.md`

`{stem}` 与该年 `prepare_financial_reports` 交回的 Markdown 文件名相同，不要改写成 `{code}_{year}年年度报告_{year}`。

目标：在单年排雷结论之上，做**跨年趋势、规则连续性、画像演变与综合定级**，而不是重写一遍各年报告。

---

## Preconditions

1. **本次任务必须是多年模式**（用户确认的年份范围 ≥ 2 年）。单年需求（只要某一年）**整步跳过**，不要生成综合报告
2. 多年模式下，本次目标年份中至少存在 **2** 份可读的 `.analysis.md`；若因降级只剩 1 份，跳过步骤 5并说明原因
3. 只使用**本次目标年份**的 `.analysis.md`；不要把目录里其他年份的旧分析算进汇总
4. 优先只读 `.analysis.md`；缺关键数字时，可回看同级主表/主要财务指标章节做轻量补数，**禁止**为汇总而全文通读各年年报
5. 各年报告中的 `R0xx`、风险评级、现金流量肖像、三大前提、必查覆盖表应直接引用，不要无依据改写

---

## Output path

```
data/reports/md/{code}/{code}_{start_year}-{end_year}_多年综合财务分析.md
```

例如近 3 年为 2023–2025：
`data/reports/md/300124/300124_2023-2025_多年综合财务分析.md`

---

## Required structure

### 1. 综合结论与多年风险定级
- 2–4 句跨年主线（质量在改善 / 恶化 / 分化）
- **多年总体风险评级**：极高风险 / 高风险 / 存疑 / 暂未发现重大财务疑点
- 相对各单年评级是否上调/下调，及原因

### 2. 数据覆盖说明
- 覆盖年份、各年 `.analysis.md` 路径
- 缺失年份或降级（如某年仅完成浅分析）须显式标注

### 3. 核心指标多年对比表
至少尽量覆盖（以各年报告已有数字为准）：
- 营收、归母净利润、扣非净利润
- 经营现金流净额、CFO/净利润、销售收现比（若有）
- 毛利率、ROE（若有）
- 应收/营收、存货相关关键比率（若有）
- 各年现金流量肖像（类型名 + 符号）
- 各年单年风险评级

### 4. 趋势分析
必须回答：
- **恶化趋势**：哪些指标/规则命中在跨年变差
- **改善趋势**：哪些在改善，是否有现金流支撑
- **拐点**：是否有某年突然跳变
- **规则连续性**：哪些 `R0xx` 跨年重复命中或由单年倾向升级为连续命中（如 R001/R013/R014/R035）
- **必查覆盖表**：对照各年覆盖表，标出跨年重复、从待验证升级为命中、以及未达阈值但趋势恶化的项（如质押比例连续攀升、账龄迁到 1 年以上）

### 5. 三表联动的跨年判断
- 收入—应收—现金：多年是否同向
- 利润—经营现金流：是否持续验证
- 资本开支—回报：扩张是否换来利润与现金
- 毛利率 × 存货周转等组合信号是否跨年持续

### 6. 三大前提（多年口径）
显式回答：
1. 利润是否为真（多年经营现金流是否持续验证）
2. 利润是否可持续（主业 vs 非经常；趋势方向）
3. 维持利润是否需要大量资本投入（自由现金流是否持续承压）

### 7. 风险分层与跟踪建议
- 高 / 中 / 低风险信号（标注发现年份与 `R0xx`）
- **覆盖表跨年**：哪些分组在多年里重复命中或升级；未达阈值但趋势恶化的项（如质押比例攀升）单独点出
- **额外重大发现**：单年报告已写但跨年更值得强调的联动信号
- P0 / P1 / P2 跟踪建议（每项含关注指标）

### 8. 待补充数据
缺少年份、缺指标、需同行对比等，按优先级列出。

---

## Tone and guardrails

- 综合报告只做风险与质量判断，不给买卖建议
- 以各年 `.analysis.md` 为证据底座；冲突时并列写出并说明采信倾向
- 不要把各年全文粘贴进综合报告；只抽取结论、评级、关键数字与规则命中
- 写完必须落盘到约定路径，并在对用户回复中给出路径
